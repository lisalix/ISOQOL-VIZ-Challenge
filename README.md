The International Society for Quality of Life Research (ISOQOL) Statistics SIG will host an inaugural data visualization challenge, PRO Viz Challenge, at the 2026 meeting. 
This team-based visualization competition will engage participants in a collaborative  event to tackle the challenges of analyzing and communicating their analysis results to academic and patient/public audiences. 
Participants in the PRO Viz Challenge will showcase their skills to tell a visual story driven by real-world PRO data. 
The PRO Viz Challenge will involve pre-symposium analysis and presentation preparation by participating teams. At the symposium, each team will present their analyses in a judged competition. 
Oral presentations will be given by each participating team in front of a panel of judges.  Each team will be given 5 minutes to present their data story to the panel of judges through innovative and creative data visualizations (charts, graphics, videos) using any software (PowerPoint, Tableau, etc.). 
Each team will highlight key findings in the data and the interpretation of these findings. Judges will evaluate each presentation using pre-defined criteria. Following the symposium, judge scores will be compiled and the top 3 teams will be identified for presentation of certificates, with the top team being given a monetary prize. 

The Challenge Dataset is a subset of the Burn Model System National Database Public Access Database. More information about the Public Access Database can be found here: http://burndata.washington.edu/about-database.
Information resources include a data dictionary and a PowerPoint presentation that guides you through the BMS Data Dictionary and provides more information about using the database. 
The subset created for the PRO VIZ Challenges includes adults (18 year to 79 years) with complete data on at least one PRO measure collected following discharge from hospital for their burn injury: anxiety, depression, drug use, fatigue, and general measures of physical and mental health. In total, the dataset includes 25 variables and more than 2000 patient records collected following discharge from hospital (PROs were not captured at the time of discharge from hospital). Many patients have 2 or more follow-up measurement occasions. 
For information about each of the variables included in the subset, please consult the Data Dictionary: https://burndata.washington.edu/bms-database/data-dictionary/
More information can be found in the Public Dataset ReadMe file. 
Note that there is a small amount of missing data on the study variables; the largest proportion of missing data is for marital status. You may choose to do multiple imputation to produce a clean dataset, but this step is not required to complete the Data Viz Challenge. 
Before using the dataset in this GitHub repo, we ask that you complete the user agreement located here: https://is.gd/bmspublicdataset
